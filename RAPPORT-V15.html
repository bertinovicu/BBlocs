Recommandations techniques

  1. Segmenter index.html
    Extraire CSS → style.css, JS → app.js pour faciliter la maintenance. Note : CLAUDE.md prescrit "inline uniquement" — à discuter avec l'équipe avant toute extraction.
  2. Smoke tests unitaires
    Ajouter au minimum des smoke tests pour les fonctions critiques : parseStaffTokens, buildStaffSVG, sanitizeStaffNotes.
  3. Version JSON schema → 2
    Passer "version": 2 dans le schema JSON pour distinguer les projets v1.0 et v1.5 et activer la migration propre.
  4. Sauvegarde automatique
    Déclencher saveProject() toutes les 5 minutes via IPC Electron pour éviter les pertes de données.
  5. Permissions micro Electron
    Déclarer "microphone" dans entitlements.mac.plist pour la release App Store — sans ça, l'enregistrement Live Memo sera refusé en production signée.
