La version 1.5 de BertinoMusicBlocs livre cinq axes de developpement majeurs : stabilite renforcee, Staff SVG solfege complet, synthese audio Web Audio API, enregistrement micro Live Memo avec waveform, et memos texte. L'application reste auto-contenue, sans dependances npm runtime, et fonctionne en navigateur natif (Safari/Chrome) comme en Electron.

Axe 1 — Stabilite

✓ LIVRE
  • Anti-overlap blocs — detection et resolution automatique des chevauchements sur la timeline
  • rebuildStaffChip() in-place — mise a jour du chip Staff sans reconstruire le DOM complet
  • _rubber global — rubber band (selection rectangle) sans accumulation de listeners d'evenements
  • pushUndo() / undo() / redo() — Ctrl+Z / Ctrl+Shift+Z — 60 niveaux d'historique
  • Validation staffNotes a l'import JSON — sanitisation complete des donnees entrantes
  • PALETTE_HIDDEN + def.internal — blocs internes caches de la palette utilisateur

Axe 2 — Staff SVG solfege

✓ LIVRE — piste desactivee par defaut
  • parseStaffTokens, keySigInfo, buildStaffSVG — pipeline 3 passes de rendu musical
  • Beaming classique — barres rectangulaires groupees, pas de flags sur notes beamees
  • Triolets qt/et, notes pointees, silences visuels (soupir, demi-soupir...)
  • Selection Ctrl+clic, navigation ↑↓←→, rubber band multiselecti ↖
  • Chip agrandissable x2 — boutons ⤤ / ⤥
  • Piste Staff — groupe system — accessible mais non creee par defaut au demarrage

Axe 3 — Audio Web Audio API

✓ LIVRE
  • getAudioCtx() — initialisation lazy du contexte Web Audio
  • noteToFreq() — conversion nom de note vers frequence Hz (A4 = 440 Hz)
  • _pianoNote() — synthese additive piano (fondamentale + harmoniques ponderees)
  • Lecture piste Staff — dormante en meme temps que la piste Staff

Axe 4 — Live Memo

✓ LIVRE
  • Enregistrement micro — getUserMedia → MediaRecorder → WebM/Opus → base64
  • Waveform generee async — blob.arrayBuffer → decodeAudioData → 80 points peak normalises
  • Waveform SVG — envelope fermee, top edge bright, bottom edge dimmer
  • Tete de lecture rouge animee via requestAnimationFrame
  • Boutons ⏺ ▶ ⏹ par lane (A et B independantes)
  • Chip — nom editable centre, waveform integree, duree + lecture + suppression
  • 2 lanes A et B — clips positionnes sur la timeline principale

Axe 4b — Memos texte

✓ LIVRE
  • Piste memos + bloc memo-text (📝 notepad) — type dedie
  • Chip notepad — fond parchemin, textarea editable inline directement dans le chip
  • Draggable depuis la palette Blocs standard
