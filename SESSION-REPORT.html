🐛 Bugs corrigés

🔴 CRITIQUE — Déclaration JS dupliquée (const parentTrack)
Deux const parentTrack dans la même fonction openBlockDetail() → SyntaxError → toute l'app ne se chargeait pas (écran noir).
→ Fusion en une seule déclaration, logique staff palette déplacée au bon endroit.
🔴 CRITIQUE — Règle détruite à chaque render()
Après déplacement de #ruler à l'intérieur de #tracks-inner, le inner.innerHTML = '' de render() supprimait la règle à chaque appel.
→ Sauvegarde de la référence $('ruler') avant le clear, réinsertion en premier.
🟡 Règle non synchronisée horizontalement
#ruler était en dehors de #tracks-scroll avec overflow: hidden → scroll horizontal ne déplaçait pas la règle → désalignement mesures/blocs.
→ Règle déplacée dans #tracks-inner avec position: sticky; top: 0.
🟡 Electron binary Windows sur macOS
node_modules/electron/dist/electron.exe → erreur EACCES au lancement.
→ rm -rf node_modules/electron && npm install → Electron.app macOS installé.
🟡 package.json malformé
Suppression des blocs win/nsis avait laissé une virgule trailing + lignes vides dans l'objet JSON → JSONParseError.
→ Réécriture propre du fichier avec le tool Write.
🟡 Icônes musicales Unicode cassées
Ronde (𝅝), blanche (𝅗𝅥), silence (𝄾) du bloc Musical Symbols U+1D100+ ne rendaient pas dans Electron → □ □□ □□□.
→ Remplacement par des SVG inline currentColor pour ronde, blanche, double croche, silence. ♩ ♪ gardés (U+2600).
🔵 Backspace/Clear staff ne rafraîchissaient pas le chip
bkBtn et clrBtn dans buildCtxStaff() modifiaient block.staffNotes mais n'appelaient pas refreshStaffChip().
→ Ajout de refreshStaffChip(block) sur les deux handlers. Fallback render() si chip introuvable.
🔵 normalizeTrackOrder manquant sur moveTrack()
Les boutons ▲▼ pouvaient déplacer une sous-piste au-dessus de STRUCTURE.
→ Appel de normalizeTrackOrder() ajouté dans moveTrack() et dans le drop handler.
