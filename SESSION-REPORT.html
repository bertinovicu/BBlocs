🐛 Bugs corrigés

🔴 CRITIQUE — Écran noir : const parentTrack déclaré deux fois
Deux const parentTrack dans la même fonction openBlockDetail() → SyntaxError au chargement → toute l'app ne démarrait pas.
→ Fusion en une seule déclaration, logique staff déplacée sous l'existante.
🔴 CRITIQUE — Règle détruite à chaque render()
Après déplacement du #ruler dans #tracks-inner, le inner.innerHTML = '' de render() supprimait la règle à chaque appel → plus aucune règle visible.
→ Sauvegarde de la référence $('ruler') avant le clear, réinsertion en premier comme pour #add-track-row.
🟡 Règle non synchronisée horizontalement
#ruler était en dehors de #tracks-scroll avec overflow:hidden → scroll horizontal ne déplaçait pas la règle → mesures décalées par rapport aux blocs.
→ Règle déplacée dans #tracks-inner, position:sticky top:0, spacer sticky left:0.
🟡 Electron binary Windows (.exe) sur macOS
node_modules/electron/dist/electron.exe → erreur EACCES spawn … ENOENT au lancement de npm run dev.
→ rm -rf node_modules/electron && npm install depuis le répertoire principal → Electron.app macOS.
🟡 package.json JSON malformé
Suppression des blocs win/nsis avait laissé une virgule trailing → JSONParseError → npm run dev échouait immédiatement.
→ Réécriture propre du fichier avec Write tool.
🟡 Icônes musicales Unicode cassées (□ □□ □□□)
Ronde 𝅝, blanche 𝅗𝅥, silence 𝄾 du bloc U+1D100+ ne rendaient pas dans Electron → boîtes □.
→ Remplacement par SVG inline currentColor. Noire ♩ et croche ♪ (U+2669/266A) conservées.
🔵 Backspace/Clear staff ne rafraîchissaient pas le chip
bkBtn et clrBtn dans buildCtxStaff() modifiaient block.staffNotes mais n'appelaient pas refreshStaffChip() → aucun retour visuel.
→ Ajout de refreshStaffChip(block) sur les deux. Fallback render() si chip introuvable dans le DOM.
🔵 moveTrack() sans normalizeTrackOrder()
Les boutons ▲▼ pouvaient faire monter une sous-piste au-dessus de STRUCTURE.
→ Appel de normalizeTrackOrder() ajouté dans moveTrack() ET dans le drop handler du drag-to-reorder.
