1 Demarrage rapide

A l'ouverture, l'application affiche l'interface principale divisee en quatre zones :

HEADER — Titre du projet, boutons Snapshot / Undo / Redo / Mode clair-sombre / Railroad
PALETTE (gauche) — Liste des blocs disponibles a glisser-deposer sur la timeline
TIMELINE (centre) — Pistes horizontales avec leurs blocs, ruler de mesures en haut
PANNEAU DROIT — Proprietes du bloc selectionne
Astuce : L'application fonctionne directement dans Safari ou Chrome sans installer Electron. Les fonctions de sauvegarde native (Cmd+S) ne sont disponibles qu'en mode Electron.

2 Les blocs

Ajouter un bloc

  1. Dans la palette a gauche, reperer le type de bloc souhaite (Intro, Verse, Chorus...)
  2. Glisser-deposer le bloc sur la piste de destination dans la timeline
  3. Le bloc se positionne automatiquement sans chevaucher les blocs existants

Manipuler un bloc

  • Deplacer : cliquer-glisser le corps du bloc
  • Redimensionner : tirer la poignee sur le bord droit du bloc
  • Muter : cliquer le bouton 🔇 sur le bloc (le bloc apparait grise)
  • Supprimer : cliquer le bouton ✕ sur le bloc, ou appuyer sur Suppr / Backspace
  • Annuler : Ctrl+Z (60 niveaux d'historique)
Chip : Chaque bloc affiche une "fiche" (chip) avec son nom et ses informations. Certains chips sont interactifs (waveform, portee, tablature).

3 Les pistes

Cliquer + Ajouter une piste en bas de la liste pour ouvrir le dialog de creation. Le flux guide en 3 etapes : nom → type → sous-type (si applicable).

🏗
Main Structure
Blocs d'arrangement principaux : Intro, Verse, Chorus, Bridge, Outro. Piste reference de votre composition.
▶
Sous-pistes
Loops, Solo, Bass, Drums... Toujours positionnees sous la Structure. Boutons ▲▼ confines dans leur zone.
📄
Lyrics
Paroles et textes. Blocs lyric-text avec textarea editable directement dans le chip.
🎸
Fretboard
Diagrammes d'accords guitare. Cordes de haut en bas : e B G D A E. Cases de gauche a droite.
🎙
Live Memo
Enregistrement micro sur 2 canaux independants A et B. Waveform visible dans le chip.
📝
Memos
Blocs-notes texte libre. Textarea editable inline dans le chip, fond parchemin.

Reordonner les pistes

Utiliser les boutons ▲ ▼ dans l'en-tete de chaque piste. Les sous-pistes restent confinee dans leur zone Structure et ne peuvent pas en sortir.

4 Snapshots & versions

  • Cliquer le bouton 🕐 Snapshot dans le header pour sauvegarder l'etat courant
  • Un badge v1, v2... apparait dans l'header
  • Cliquer sur le badge de version pour ouvrir le dropdown des snapshots disponibles
  • Cliquer un snapshot dans la liste pour le restaurer (une confirmation est demandee)
Conseil : Prendre un snapshot avant chaque modification importante. Les snapshots sont sauvegardes dans le fichier .bmb lors de l'export.

5 Live Memo

La piste Live Memo permet d'enregistrer des idees vocales ou instrumentales directement dans l'app, sur 2 canaux independants A et B.

Enregistrer

  1. Sur la lane A ou B, cliquer le bouton ⏺ Enregistrer
  2. Autoriser l'acces au microphone si le navigateur le demande
  3. Parler, chanter ou jouer
  4. Cliquer ⏹ Arreter — le clip est cree automatiquement sur la timeline

Dans le chip du clip

  • Nom editable : cliquer sur le texte du chip pour le modifier
  • Waveform : la forme d'onde est visible (envelope SVG, top bright / bottom dimmer)
  • Tete de lecture rouge : se deplace pendant la lecture via requestAnimationFrame
  • Duree : affichee en secondes dans le chip
  • Bouton ▶ : lire le clip
  • Bouton ✕ : supprimer le clip
Note : La waveform peut apparaitre vide a la premiere ouverture d'un projet sauvegarde. Elle s'affiche correctement apres la deuxieme ouverture (decode audio asynchrone).

6 Memos texte

  1. Dans la palette Blocs, reperer 📝 Memo projet
  2. Le glisser-deposer sur la piste Memos dans la timeline
  3. Le chip s'ouvre avec un fond parchemin et une zone de texte
  4. Cliquer directement dans le chip pour saisir ou modifier le texte
Ideal pour : notes d'arrangement, paroles en cours, references d'accords, tempo, tonalite...

7 Fretboard

La piste Fretboard affiche des diagrammes d'accords de guitare en vue standard :

  • Orientation : cordes de haut en bas : e (mi aigu) B G D A E (mi grave)
  • Cases : de gauche (case 1) a droite (cases superieures)
  • Placer un doigt : cliquer sur l'intersection corde/case
  • Retirer un doigt : re-cliquer sur le point existant
  • Agrandir le chip : redimensionner le bloc (poignee droite) pour voir plus de cases
  • Nom de l'accord : affiche en haut du chip, editable

9 Vue Railroad 🚊

La vue Railroad est une representation lineaire et epuree de votre structure, optimisee pour l'impression ou la presentation sur scene.

  • Cliquer le bouton 🚊 Railroad dans le header pour activer la vue
  • Seules les pistes de structure et sous-pistes sont affichees
  • Les pistes techniques (Live Memo, Memos) sont exclues
  • La vue est imprimable via Cmd+P
  • Cliquer a nouveau sur Railroad pour revenir a la vue normale

10 Collapse des en-tetes

Pour maximiser l'espace de la timeline, les labels de piste peuvent etre collapses en mode icone.

  • Cliquer le bouton ◇ dans le coin du ruler (en haut a gauche de la timeline)
  • Les en-tetes passent de 220px a 36px (icone seule visible)
  • Cliquer ◆ pour revenir a la vue complete
  • Inspiré du comportement Logic Pro

Skills & Agents Claude

Commandes slash disponibles dans Claude Code pour ce projet et en global. Invoquer avec /nomSkill dans le chat.

SKILL /versionupdate

Bumpe la version du projet au format vX.XX-DDMMYY (convention date du jour). Détecte automatiquement package.json, splash.html, VERSION, pubspec.yaml… Met à jour tous les fichiers, committe et propose un push/tag.

InvocationEffet
/versionupdateDemande la version cible, date = aujourd'hui
/versionupdate 1.52Applique v1.52-DDMMYY automatiquement
/versionupdate 2.0 150726Version + date fournie manuellement
/versionupdate --minorIncrémente le minor de la version courante

⚡ Fonctionne sur tout type de projet : Electron, Node, Flutter, Python, web.

SKILL /twineyes

Test d'acceptation bicéphale. Deux axes simultanés :

  • eyeonreal (vertical) — parcourt chaque menu, bouton, champ et valide "ça fait ce que ça prétend faire"
  • eyeontime (horizontal) — trace chaque entrée jusqu'à sa sortie, détecter les couplages cachés et les fuites de données

Produit 3 rapports Markdown incrémentés sous reports/twineyes/. Read-only par défaut.

SKILL /briefair

Génère un briefing de session — résumé en <60s de l'état du projet. Lit SCOPE.md, journaux quotidiens, derniers rapports twineyes/blueagent, commits récents. Produit BRIEF.md. Utile en début de session pour retrouver le contexte.

SKILL /blueagent

Inspector Audit Agent — analyse structurée en 6 étapes : sanctuarisation du code, deep check, roll-fix sécurité, pivots architecture, fluidité logique, rapport HTML incrémenté. Mode read-only par défaut.

SKILL /dayclosed

Journal de fin de session. Résume la session courante et l'ajoute dans reports/daily_YYYY-MM-DD.md. Append-only — n'écrase jamais les entrées précédentes. À invoquer en fin de journée de travail.
