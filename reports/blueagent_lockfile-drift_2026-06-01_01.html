TL;DR — Ce qu'il faut faire et pourquoi

Le fichier package-lock.json affiche encore la version 1.5.0 alors que package.json est passé à 1.51.0-010626. Ce décalage est inoffensif pour le build local (electron-builder lit package.json), mais il crée du bruit dans les diffs et bloquerait un npm ci strict (futur CI). Il suffit de committer le lockfile tel quel — ou de relancer npm install après le bump pour l'aligner automatiquement. Aucun bloquant de sécurité ni d'architecture. Un seul ticket : aligner le lockfile.
